# Collections.conf 能解锁的 App 清单

来源：chxm1023 Script_X 的 Collections.conf（App 解锁合集）。每个名字点开是 App Store 搜索，直达对应 App。
注意：这份合集只是“有对应的改写规则”，不等于每个都实测有效；个别条目在源文件里是被注释掉的（不生效），已尽量排除。

## 订阅平台合集（不是单个 App）

- **RevenueCat 系列**：433 个 App（Reheji.js），清单见之前那份 `reven-unlock-apps.md`
- **iTunes 系列**：通用苹果收据伪造，没有固定清单，哪个 App 在客户端调 verifyReceipt 就能试
- **Bending 系列**：Bending Spoons 旗下 App（bending.js）
- **Adapty 系列**：用 Adapty SDK 的 App（adapty.js）
- **Qonversion 系列**：用 Qonversion SDK 的 App（qonversion.js）
- **Apphud 系列**：用 Apphud SDK 的 App（apphud.js）
